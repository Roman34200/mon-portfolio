Le projet

Conception et réalisation complète d'un robot sumo autonome. SolidWorks pour la mécanique, STM32 en C pour l'embarqué — chaîne de développement complète.

Capteurs de distance pour détecter l'adversaire, capteurs de ligne pour rester dans l'arène, stratégie embarquée pour optimiser les attaques.

Compétences mobilisées

SolidWorks, impression 3D, KiCad, STM32 C — interruptions et timers.

Intégration complète : câblage, alimentation, tests, débogage.
